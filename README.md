# DraVeterinariaMobile
# Recordatorio
Trabajo se encuentra en la rama de develop


Aplicación móvil del sistema DraVeterinaria Desarrollado por: Marvin Francisconi Sebastian Vélez es una aplicación móvil desarrollada en Kotlin usando Android Studio que permite a los usuarios gestionar la información de sus mascotas y programar citas o recordatorios importantes relacionados con su cuidado.

# Características principales
Registro de mascotas: Agregar, editar y eliminar información de cada mascota (nombre, especie, raza, edad, foto, etc.).

Gestión de tutores: Registrar y vincular información del propietario o tutor de cada mascota.

Agenda de citas: Crear y gestionar citas para veterinario, vacunas, baños, entre otros.

Interfaz intuitiva: Navegación fluida con Jetpack Compose y formularios validados.

# Tecnologías utilizadas
Lenguaje: Kotlin

IDE: Android Studio

UI: Jetpack Compose

Arquitectura: MVVM (Model-View-ViewModel)

Gestión de dependencias: Gradle

# Uso
Abrir la aplicación y crear un perfil de mascota.

Registrar información del tutor asociado.

Agregar citas o recordatorios para cada mascota.

Recibir notificaciones en las fechas programadas.

Editar o eliminar mascotas y citas según sea necesario.
